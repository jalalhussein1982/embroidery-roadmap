## A. Account type and settings

- [ ] **Switch Creator → Business.** Settings → Account type and tools → Switch to professional account → Business. (Creator keeps the follower count; nothing is lost.)
- [ ] **Category:** change *Artist* → **Gift Shop** (primary) or *Personalized Gifts* if offered. Do **not** use "Arts & Crafts Store" — that signals supplies. The category feeds Instagram's topic classification and the Explore/Reels distribution.
- [ ] **Contact buttons:** enable Email and WhatsApp/Call. Business profiles get an "Order" style action button — set to the order form link (see C).
- [ ] **Connect a Facebook Page** (required for Instagram Shopping later and for Meta Business Suite scheduling). Create a bare Facebook Page with the same name; it needs no content.
- [ ] **Meta Business Suite:** log in at business.facebook.com. Use it for scheduling, inbox, and Insights. This also gives access to *Saves* and *Shares* — the two metrics the audit couldn't see and the ones that actually track enquiries.
- [ ] ⚠ **Business address / IČO:** Czech law requires a trader to be identifiable in commercial communications. Put "IČO: xxxxxxxx" in the bio or on the linked page (link page is sufficient and cleaner).
- [ ] **Turn on "Show account suggestions"** and **"Allow tagging" → Everyone**, **"Mentions" → Everyone**. Customers must be able to tag.
- [ ] **Set default reply language:** none needed, but keep the rule: reply in the commenter's language.

## B. Language policy

Decision: **Czech first, English second, on every post — no exceptions.** 16 Czech-only captions currently exclude the expat market the page is best placed to win.

Format per caption:

```
[Czech text · 2–4 lines]
—
[English text · 2–4 lines]
—
[CTA line in both: "Napište mi DM / Send me a DM · 🔗 odkaz v bio / link in bio"]
[hashtags]
```

- Keep captions **under 500 characters** of body text. Current average 987 is a product description; move dimensions/materials into carousel slide 2 or the order page.
- Stories: text overlay in Czech with an English line below, or alternate days.
- Story polls/questions: bilingual in the sticker itself ("Medvěd nebo králík? / Bear or bunny?").

## G. Hashtags and location

- [ ] **Location tag on every post and story:** "Prague, Czech Republic" or a specific district (Vinohrady, Letná, Karlín). This is the single cheapest change with the largest effect on local distribution.
- [ ] **Hashtag set — 8–12 per post, three tiers:**

| Tier | Purpose | Tags |
|---|---|---|
| Local (always) | Prague distribution | `#praha` `#prague` `#ceskyhandmade` `#czechhandmade` `#handmadepraha` |
| Occasion (pick by post) | Reach the gift-giver | Baby: `#miminko` `#tehotenstvi` `#novorozenec` `#darekpromiminko` `#babygiftideas` · Wedding: `#svatba2026` `#svatba2027` `#svatebnidar` `#weddinggiftideas` `#czechwedding` · Pets: `#psipraha` `#dogportrait` |
| Expat (pick by post) | English-speaking Prague | `#pragueexpats` `#expatsinprague` `#praguemoms` `#praguelife` |

- [ ] **Drop:** `#handembroidery` (7.7M — invisible), `#nurserydecor` (4.4M). Keep `#vysivka` at most once per post as a niche identifier.
- [ ] Put hashtags in the caption, not the first comment (Instagram now indexes captions for keyword search — the caption text itself should contain "personalised gift Prague / dárek na míru Praha").

## H. Posting system

- [ ] Schedule in Meta Business Suite. Slots: Tue/Wed/Thu 11:30, Sun 19:00 (Sunday evening is the gift-planning hour; currently 1 post on weekends).
- [ ] **Per project, produce the asset set before posting anything:**
  1. Process reel (10–15 s, original audio or trending audio — not licensed catalogue tracks, which limit reach and can be muted)
  2. Reveal reel (5–8 s, hook in first second: the finished piece, then the stitch)
  3. Carousel: piece in situ (on the wall / on the table) → detail → packaging → "how to order" slide
  4. Story series over 3 days
  5. Client reaction / tagged photo when it arrives
- [ ] **No duplicate captions.** Re-showing a piece is fine; re-posting the same caption is not.
- [ ] Reels: add on-screen text (most viewers watch muted) and a 3-word hook in the first frame ("Pro malého Viktora / For baby Viktor").
- [ ] Stories: daily, using the angle rotation in file 01 §2. Use polls, questions and the "Add yours" sticker weekly.
